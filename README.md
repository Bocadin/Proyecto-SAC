# Proyecto-SAC
SAC es un software en Python y CustomTkinter que optimiza la gestión de condominios. Centraliza el control de residentes, pagos, adeudos y servicios mediante una interfaz gráfica profesional e intuitiva. Almacena los datos en archivos CSV, reemplazando los procesos manuales para reducir errores, ordenar reportes y agilizar la administración.
